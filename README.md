## Web Scraping

### Project Description

Web Scraping is a project designed to access information from the Sicredi Conexão website and extract product details from the cooperative. The extracted data (name, image, URL, and category) is saved in a CSV file for easy further use.

### Project Docs

- [Installation Guide](https://github.com/carloseduardorocha/web-scraping/wiki/Installation-Guide) - Step-by-step instructions to install the project and run the data extraction script.

### Technologies Docs

The project was developed using the following technologies:

- [Python 3.x](https://docs.python.org/3/) - Programming language. <br/>
- [Playwright](https://playwright.dev/python/docs/intro) - Library for automating web browsing. <br/>
- [dotenv](https://pypi.org/project/python-dotenv/#getting-started) - Loading environment variables from .env files. <br/>

## 🚨 **Practical Test Execution Flow** 🚨

To ensure the correct execution of the project, follow the steps below in the exact order. This will guide you through the installation, configuration, and execution of the script:

### 1. **Install the Project**

- Follow the [Installation Guide](https://github.com/carloseduardorocha/web-scraping/wiki/Installation-Guide) to install the project in your development environment.

### 2. **Run the Python Script**

- To run the script that extracts product data and generates the CSV, execute the following command: `python src/extract_csv_files.py`
- The script will visit the Sicredi Conexão website, collect the product information, and save the data in the results/products.csv file.
